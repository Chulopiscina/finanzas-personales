# Firmar Finanzas Bancarias

1. Descomprime este paquete en **Descargas** de un Mac con Atajos y sesión iCloud.
2. Abre Terminal y ejecuta:

```bash
bash "$HOME/Downloads/Finanzas-Bancarias-para-firmar/firmar-en-Mac.sh"
```

3. Devuelve el archivo **Finanzas Bancarias.shortcut** que se creará en esta carpeta.

No hace falta crear acciones, copiar tokens ni compartir contraseñas. No instales
el archivo `_unsigned` en el iPhone. La firma no prueba la entrega de avisos de
ningún banco; esa prueba se hará después de desplegar la versión universal.

El script no sobrescribe una firma existente. Si falla por iCloud, abre la sesión
personalmente en el Mac; nunca entregues tu contraseña Apple al agente.
